টোকেন শুধু এই ব্রাউজারে সংরক্ষিত থাকে (localStorage; এক্সটেনশনে অতিরিক্ত extension storage-এও)। এখানে যা-ই লিখুন/বদলান, সাথে সাথে স্বয়ংক্রিয়ভাবে সংরক্ষিত হয় — প্রতিবার দিতে হবে না। HTML ফাইলে বা রিপোতে কখনো লিখবেন না। সেভ/পুশ করতে টোকেনে এই রিপোর জন্য Contents: Read and write অনুমতি লাগবে।
Google অনলাইন অডিও একটি অনানুষ্ঠানিক সার্ভিস (Google Translate-এর অডিও), তাই যেকোনো সময় বন্ধ বা সীমিত হতে পারে। এতে ভয়েস বাছা যায় না; ভাষা (বাংলা/আরবি/ইংরেজি) নিজে থেকে চেনা হয়। এখানে শেষ বাছাই দেখায়। "শুনুন" বোতাম চাপলে প্রতিবার সার্ভিস বাছার ডায়ালগ আসে (সেখানে সব সার্ভিসের কনফিগও আছে)। ফোনের ভয়েস ডিভাইসের টেক্সট-টু-স্পিচ ইঞ্জিন থেকে আসে (শুধু ফোনের TTS ব্যবহার হলে প্রযোজ্য)। "স্বয়ংক্রিয়" রাখলে ডিভাইসের সেরা মিল ব্যবহার হবে।

API

এপি আই এখন বন্ধ (অ্যাডমিন সেটিংস থেকে চালু করুন) — চালানো যাবে না, শুধু কনফিগ দেখা/বদলানো যাবে।

শর্ত: Key দেওয়া আছে, পেইজের টেক্সট ফাঁকা (txt নেই/খালি, খসড়াও নেই), পেইজটি প্রুফড নয়। প্রতি পেইজে সেশনে একবারই অটো চলে। কী, মডেল, প্রম্পট ইত্যাদি শুধু এই ব্রাউজারে (localStorage; এক্সটেনশনে extension storage-এও) থাকে। কিছু বদলালেই সাথে সাথে স্বয়ংক্রিয়ভাবে সংরক্ষিত হয় — একবার দিলে পরেও একই থাকবে। রিপোতে কখনো যায় না।

কোন সার্ভিসে শুনবেন?

একটি সার্ভিস বেছে নিন, দরকার হলে তার কনফিগ (কী / ভয়েস / URL) দিন, তারপর "শুনুন" চাপুন। কনফিগ এই ব্রাউজারে থেকে যায় (আবার লিখতে হবে না); শোনা শুরুর সময় প্রতিবার এই তালিকা আসবে, যাতে সার্ভিস বদলে নিতে পারেন।
