# RizwanTask

কিতাব প্রুফিং ওয়েব অ্যাপ (Supabase + GitHub + Gemini)।

## পেইজ
- `index.html` — splash স্ক্রিন (লোডিং অ্যানিমেশন), তারপর লগইন/টাস্কে পাঠায়
- `login.html`, `signup.html`, `task.html`, `view.html`, `admin.html`
- `common.css` / `common.js` — শেয়ার্ড লেআউট ও ক্লায়েন্ট
- `theme.css` — ইসলামি থিম: জামরুদ সবুজ + সোনালি ঝিলিমিলি, গম্বুজ/চাঁদ-তারা/গোলাপ-নকশা (সব পেইজে)
- `icon.svg` — ফেভিকন

## এপি আই চালু/বন্ধ
অ্যাডমিন প্যানেল → সেটিংস → "এপি আই নিয়ন্ত্রণ" টগল।
বন্ধ থাকলে view.html-এ কোনো এপি আই (OCR/অটো OCR/প্রুফিং) চলে না; স্ট্যাটাস লাইনে
`টেক্সট নেই (পেস্ট করে সেভ করুন) • এপি আই বন্ধ` দেখায়।

প্রথমবার Supabase SQL Editor-এ `supabase_api_toggle.sql` চালান (নতুন কলাম `app_settings.api_enabled`)।

## ইউজার-ভিত্তিক প্রুফড পেইজ
একজন ইউজার কোনো পেইজ প্রুফড করলে সেই পেইজ শুধু সে (ও অ্যাডমিন) দেখতে পায়। অন্য ইউজারের কাছে পেইজটি
ড্রপডাউন, আগে/পরে বাটন (Alt+←/→), নম্বরে যাও ও "পরের অপ্রুফড" থেকে বাদ যায়; যেসব পেইজ কেউ প্রুফড করেনি
সেগুলো সবাই আগের মতোই পায়। একই পেইজ দুইজন একসাথে প্রুফড করতে গেলে যে আগে করেছে সে-ই মালিক হয়।
- প্রথমবার Supabase SQL Editor-এ `supabase_page_proofs.sql` চালান (নতুন টেবিল `page_proofs`)।
- টেবিল না থাকলে view.html আগের মতো চলে (সবাই সবকিছু দেখে) এবং অ্যাডমিনকে সতর্কবার্তা দেয়।
- এই সুবিধা অ্যাপের ইন্টারফেসে লুকানো; ব্রাউজারে সার্ভিস-কী ব্যবহৃত হওয়ায় এটি কঠোর নিরাপত্তা-বেষ্টনী নয়।
- সিস্টেম চালুর আগে `proofed.json`-এ থাকা পুরনো প্রুফড পেইজের মালিক জানা নেই, তাই সেগুলো সবার জন্য আগের মতো খোলা থাকে।

## সম্পন্ন টাস্কের সংখ্যা (বাংলা সংখ্যায়)
`task.html`-এর উপরের টুলবারে (ডান পাশে, ✓ ৫ টি সম্পন্ন) ও প্রোফাইল ট্যাবে (৫ টি টাস্ক সম্পন্ন) ইউজারের নিজের সম্পন্ন (প্রুফড) পেইজের মোট সংখ্যা দেখায়। `view.html`-এ ডাউনলোড/Lens/AI বাটনের লাইনের মাঝখানে একই সংখ্যা শুধু বাংলা অঙ্কে দেখায় (প্রুফড চিহ্ন দিলে/তুললে নিজে হালনাগাদ হয়)। প্রতিটি ইউজার শুধু নিজেরটাই দেখে (`user_id` দিয়ে ফিল্টার)।
- Supabase SQL Editor-এ `supabase_task_count.sql` চালান (ফাংশন `my_proof_count`; ফাংশন না থাকলে অ্যাপ সরাসরি গুনে নেয়)।
- view.html থেকে ফিরলে বা রিফ্রেশ চাপলে সংখ্যা নতুন করে আসে।

## আরবি/উর্দু ফন্ট ও টেক্সটের দিক (view.html)
- টেক্সট বক্সে আরবি/উর্দু অক্ষরে **Noorehuda** ফন্ট ব্যবহার হয় (`fonts/Noorehuda.ttf` রাখুন — `fonts/README.md` দেখুন); বাংলা ফন্ট আগের মতোই।
- টেক্সট সব সময় **LTR** (বাম দিক থেকে শুরু), আরবি লাইনও বামে সারিবদ্ধ।
